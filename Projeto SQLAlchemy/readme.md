# Programa simples
Fiz esse programinha pra codar algo depois de passar um tempo fora. Consiste só em um CREATE básico usando **SQLAlchemy** que eu estudei recentemente e **requests** para fazer a requisição da API [PokéAPI](https://pokeapi.co/). Também usei type hints na criação do código como forma de praticar(não interfere em runtime).

---

Tá tendo conflito na execução do código de forma direta, portanto, para rodar execute:  
`py main.app` | `python main.app`
